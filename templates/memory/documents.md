# Documents & links

> Files and links that application forms may ask for. Each file is identified, renamed clearly and
> moved into its section folder under `memory/documents/`; resumes go to `memory/resume/`.
> Files sitting directly in `memory/documents/` are new and not filed yet.
> /apply uploads the matching file when a form asks for one, and uses the links for link fields.
>
> Never store identity or bank documents here (passport, Aadhaar, PAN, driver's license, bank statements).
> Shiro won't upload them; do those yourself if a form ever asks.
